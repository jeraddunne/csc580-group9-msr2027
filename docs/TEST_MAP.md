# Report outputs and their tests

This page maps every table and figure that `report/draft.md` cites to the function that produces it and the automated tests that check its values. It answers the Sprint 2 acceptance check in #22: every function whose output appears in the report has a corresponding automated test.

The tests run on small synthetic inputs whose expected values were worked out by hand, so they check the calculation, not the dataset. `tests/test_analysis.py::test_cli_analyze_writes_outputs` also runs `python -m msr_pipeline analyze` on the sample data and checks that every table in `analysis.OUTPUT_TABLES` and every figure in `analysis.OUTPUT_FIGURES` is written. CI runs all of them on every pull request (`.github/workflows/ci.yml`, Python 3.11 and 3.12).

| Report output | Produced by | Tests | What the tests check |
|---|---|---|---|
| `results/population_flow.csv` | `analysis.population_flow`, `skill_risk.population_flags` | `test_analysis.py`: `test_population_flow_counts_each_step`, `test_population_flags_and_symlink_stub`, `test_population_flags_exclude_unrecovered_content` | Distinct contents and occurrences at each of the six inclusion steps; which contents each flag excludes |
| `results/rq1_prevalence_by_rule.csv` | `analysis.rq1_tables`, `skill_risk.rule_prevalence` | `test_analysis.py`: `test_rq1_prevalence_by_rule_values`, `test_wilson_ci_known_values` | Contents, occurrences, both shares, and the Wilson interval per rule and for `ANY_HIGH_RISK` |
| `results/rq1_prevalence_by_category.csv`, `figures/rq1_prevalence_by_category.png` | `analysis.rq1_tables`, `analysis.high_risk_by_category`, `analysis.plot_prevalence` | `test_analysis.py`: `test_high_risk_by_category_excludes_context_rules`, `test_wilson_ci_known_values` | High-risk contents and occurrences count only rules at the high-risk severity, not context rules |
| `results/rq2_reach_summary.csv`, `figures/rq2_copies_by_group.png` | `analysis.rq2_reach_summary`, `analysis.plot_copies_by_group` | `test_analysis.py`: `test_rq2_reach_summary_values` | Per group: contents, occurrences, mean and median copies, shares copied 2, 5, and 10 or more times, cross-repository share, maximum; an empty group |

| `results/rq2_bootstrap.csv` | `analysis.rq2_bootstrap`, `analysis.bootstrap_difference` | `test_analysis.py`: `test_rq2_reach_summary_values`, `test_bootstrap_is_deterministic_and_brackets_estimate` | Both estimates on hand-computed data; same seed gives the same interval, and the interval contains the estimate |

| `results/scripts_summary.csv` | `analysis.scripts_summary` | `test_analysis.py`: `test_scripts_summary_with_and_without_truncated_listings` | Script files with and without text, high-risk scripts, and the same metrics without truncated folder listings |
| `results/sensitivity_summary.csv` | `analysis.sensitivity_summary`, `analysis.with_severity_cutoff`, `analysis.key_metrics` | `test_analysis.py`: `test_sensitivity_summary_membership_and_results`, `test_with_severity_cutoff_changes_flags` | For all six scenarios: which contents are in it, high-risk count and share, its interval, mean copies per group and their ratio; no test when a group has one content |
| `results/validation_precision_by_category.csv` | `validation.precision_by_category` | `test_validation.py`: `test_precision_by_rule_and_category` | Strict and capability precision with Wilson intervals; an unlabelled rule shows n = 0, and low-severity rules are left out |
| `results/validation_agreement.csv` | `validation.agreement`, `validation.cohen_kappa` | `test_validation.py`: `test_agreement_classifies_comparisons`, `test_cohen_kappa_textbook_example`, `test_cohen_kappa_degenerate_and_empty` | Which file pairs are inter-rater, intra-rater, or human-vs-LLM; kappa on a textbook table; undefined kappa explained in `kappa_note` |

Figures are drawn from the tables in the same row, so their numbers are covered by those tests; the plotting functions themselves are only checked for writing the file.
