# Decision records

How to use: every decision that affects scope, method, the research question, tooling, or process gets an Architecture Decision Record (ADR) within 48 hours. Copy `ADR-template.md`, number it sequentially, open a pull request, and link the `decision` issue. Every decision, big or small, also gets a row in `docs/workspace/DECISION_LOG.md`.

Status values: Proposed, Accepted, Superseded by ADR-NNNN, Rejected.
