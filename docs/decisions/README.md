# Decision records

How to use: every decision that affects scope, method, the research question, tooling, or process gets an Architecture Decision Record (ADR) within 48 hours. Copy `ADR-template.md`, number it sequentially, open a PR, link the `decision` issue.

Status values: Proposed, Accepted, Superseded by ADR-NNNN, Rejected.

| ADR | Title | Status | Date |
|---|---|---|---|
| 0001 | Run the project with Scrum plus a Lean Six Sigma overlay | Accepted | 2026-09-13 |
| 0002 | Select the topic by proposal issues and a ranked ballot | Accepted | 2026-09-13 |
| 0003 | Repository structure, tooling, and branch policy | Accepted | 2026-09-13 |
| 0004 | Topic selection | Proposed | 2026-09-16 (planned) |

Rubric note: the retrospective must also record changes to the research question, method, scope, or interpretation. Link the ADR from the retrospective file.
