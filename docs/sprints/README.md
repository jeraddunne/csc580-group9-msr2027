## Definition of Ready and Definition of Done (summary)

Full text lives in `docs/PROCESS.md`.

Definition of Ready (an issue may enter a sprint when):
- [ ] It has a meaningful description and at least one acceptance criterion.
- [ ] It is linked to a milestone and carries a `type:` label and an estimate (1, 2, 3, 5, or 8 points).
- [ ] Dependencies and needed data are identified.

Definition of Done (an issue may move to Done when):
- [ ] The work is on `main` through a pull request that passed the self-review protocol (at least 12 hours of cooling-off, checklist, review comment; ADR-0005).
- [ ] Tests pass (in CI once enabled), and any generated tables or figures are regenerated by the pipeline, not pasted in.
- [ ] Documentation touched by the change (README, data dictionary, threats, decisions) is updated.
- [ ] The pull request links the issue, describes testing, and names generated outputs.

Board statuses: Todo, In progress, Done, Block, Cancelled. WIP limit: 5 on the board, at most 2 In progress at once.
