## 3. Working rules

- Hold at most two issues **In progress** at once. The board WIP limit of five still applies to the whole board.
- Assign every issue to yourself when you start it, so cycle-time metrics work.
- If an issue sees no activity for 72 hours, move it back to **Todo** with a comment, or mark it **Block** with the reason.
- If the sprint is at risk, apply the descope order from ADR-0005 and record it in DECISION_LOG.md.
