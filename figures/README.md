# figures/

Figures generated by code (PNG or SVG). Nothing in this folder is edited by hand.

- Naming matches the results table the figure is drawn from: `gitskills_location_summary.png` comes from `results/gitskills_location_summary.csv`.
- Produced only through `python -m msr_pipeline ...` or `make figures`; the report references them as `../figures/<name>.png`.
- Keep figures readable in greyscale and at report width; label axes with units; state the dataset snapshot in the caption, not the image.
