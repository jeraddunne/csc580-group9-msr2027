# results/

Tables generated by code. Nothing in this folder is edited by hand.

- Naming: `<dataset>_<what>.csv` for exploratory tables (for example `gitskills_location_summary.csv`); `rq_<n>_<what>.csv` for research-question results once the question is chosen.
- Every file here is produced by a command that appears in the pull request that added it (PR template, "Generated outputs").
- Regenerate everything with `make figures` (alias of the pipeline run). The Sprint 3 review checks that `git diff` is empty after regeneration.
- Large intermediates (Parquet, temporary files) go to `results/tmp/` and are ignored by git.
